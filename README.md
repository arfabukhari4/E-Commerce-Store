# E-Commerce-Store
Python-based E-Commerce Store with product catalog, shopping cart, inventory, orders, billing, customer management, and database integration.
## 📌 Project Overview

The **Professional E-Commerce Store Desktop Application** is a Python-based desktop shopping system developed using **Tkinter GUI**.

The project demonstrates how Python can be used to build a complete desktop-based e-commerce workflow with a clean graphical interface and modular architecture.

Users can register and log in, browse products, search and filter the catalog, add products to their cart or wishlist, manage orders, view their profile, and interact with different parts of the shopping system.

The project was developed with a focus on:

- Clean user interface design
- Object-Oriented Programming
- Modular Python development
- User authentication
- Product management
- Shopping cart functionality
- Wishlist management
- Order history
- Profile management
- Input validation
- Beginner-friendly architecture

---

## 🎯 Project Objectives

The main objectives of this project are:

- Build a functional desktop-based e-commerce application.
- Implement a professional GUI using Python Tkinter.
- Practice Object-Oriented Programming concepts.
- Create reusable and modular Python components.
- Implement customer registration and login.
- Develop product browsing and search functionality.
- Implement shopping cart and wishlist features.
- Manage customer orders and order history.
- Provide profile management functionality.
- Strengthen Python GUI development and software design skills.

---

## ✨ Key Features

### 🔐 User Authentication

- Customer Login
- Customer Registration
- Username and password validation
- Duplicate username checking
- Show/Hide password functionality
- Clear form functionality
- Navigation between Login and Registration

### 🏠 Customer Dashboard

The dashboard provides a centralized overview of the customer's account.

Features include:

- Welcome message
- Order statistics
- Cart item count
- Wishlist count
- Reward points
- Featured products
- Quick access to shopping functionality

### 🛒 Product Catalog

The product catalog allows customers to explore available products.

Features include:

- Product cards
- Product categories
- Product prices
- Stock status
- Product ratings
- Product descriptions
- Search functionality
- Category filtering
- Product details
- Add to Cart
- Add to Wishlist

### 🛍️ Shopping Cart

Customers can manage products before checkout.

Features include:

- Add products to cart
- Remove products
- Increase quantity
- Decrease quantity
- View product price
- View quantity
- Calculate subtotal
- Track cart item count

### ❤️ Wishlist

The wishlist allows customers to save products for later.

Features include:

- Add products to wishlist
- Prevent duplicate wishlist items
- View saved products
- Move products to cart
- Remove wishlist items

### 📦 Order History

Customers can view previous orders.

Features include:

- Order ID
- Customer information
- Order date
- Purchased products
- Total amount
- Payment status
- Delivery status
- Search orders
- Sort orders
- View order details
- View invoice
- Repeat order

### 👤 Customer Profile

Customers can manage their registered information.

Features include:

- View username
- View full name
- View email
- View phone number
- View address
- Edit profile information
- Save updated information
- Change password

### 🚪 Session Management

- Logout functionality
- Exit application functionality
- Navigation between application windows
